# Environmental Monitoring Station

## Sensor
DHT11

## Library Used
DHT by Adafruit

Library Version: 1.4.6

## Features

- Reads temperature in Celsius and Fahrenheit.
- Reads humidity.
- Displays data every 2 seconds in CSV format.
- Red LED turns ON if temperature > 35°C or humidity > 80%.
- Green LED turns ON when conditions are normal.
